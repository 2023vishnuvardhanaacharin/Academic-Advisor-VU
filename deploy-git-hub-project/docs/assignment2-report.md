# Assignment 2 Report Summary

## Goal
The project extends the original academic advisor into a secure, multimodal, and agentic academic support system.

## Phases delivered

### Phase 8 — Multimodal Extension
The app demonstrates a meaningful multimodal user experience with:
- a text-based academic advisor
- an academic infographic summarizing course planning
- a spoken audio explanation for regulation-oriented advice

### Phase 9 — Agentic Extension
The design separates the workflow into several agents:
- Regulation Retrieval
- Course Eligibility
- Credit Calculation
- Recommendation
- Verification

This is compared against the original RAG system to show why the additional workflow is valuable and when it should not be used.

### Phase 10 — Privacy & Security Audit
The dashboard lists sensitive information risks, unauthorized-access scenarios, prompt injection concerns and safeguards.

### Phase 11 — Legal and Ethical Review
Three AI outputs are evaluated for ownership, attribution, licensing, misuse risk, and responsible-use practices.

### Phase 12 — Deployment and Demonstration
The project is packaged as a deployed prototype UI with a presentation-ready dashboard and supporting documentation.

## Important responsibility note

The assignment requires a careful balance between functionality and responsible AI use. The design therefore focuses on traceability, privacy, and human review rather than pretending that an AI model alone is sufficient for academic decisions.
